# 네이버 통합검색 블로그 순위 확인

검색 키워드와 블로그명을 여러 줄로 입력하면, 키워드마다 각 블로그가 몇 번째 일반 검색 결과로 나타나는지 표로 비교하는 로컬 웹서비스입니다.

## 실행하기

Node.js 22 이상이 필요합니다. 저장소를 내려받고 프로젝트 폴더에서 실행하세요.

```sh
npm install
npx playwright install chromium
npm start
```

브라우저에서 **http://127.0.0.1:3210/** 을 엽니다. Windows에서는 설치를 마친 뒤 `start.cmd`를 더블클릭해도 됩니다. 실행 창을 닫으면 서비스가 종료됩니다.

Vercel에서는 이 저장소를 가져와 배포할 수 있습니다. `vercel.json`이 정적 화면과 검색 API를 설정하며, 서버에서는 별도 Chromium을 사용합니다. Node.js 22와 서울 리전을 사용합니다. GitHub Pages만으로는 검색 서버를 실행할 수 없습니다.

## 사용하기

1. 검색 키워드를 한 줄에 하나씩 입력합니다. 최대 20개입니다.
2. 찾을 블로그명을 검색 결과의 프로필 사진 옆에 보이는 이름으로 입력합니다. 한 줄에 하나씩, 최대 20개입니다.
3. 20·50·100위 중 범위를 선택하고 **순위 확인**을 누릅니다.
4. 완료된 키워드부터 표에 순위가 표시됩니다. **발견된 글**을 펼치면 제목과 링크를 볼 수 있습니다.

같은 키워드는 한 번 수집한 결과에서 모든 블로그명을 비교합니다. 빈 줄과 중복 입력은 정리하며, 이름은 앞뒤·연속 공백만 정리한 후 정확히 비교합니다. ‘범위 내 없음’과 ‘조회 실패’를 구분하고, 일부 키워드가 실패해도 다음 조회를 계속합니다.

## 순위 기준과 제한

- 로그인하지 않은 PC 네이버 **통합검색** 기준입니다. 블로그·VIEW 탭의 순위가 아닙니다.
- 광고, 플레이스, 별도 쇼핑 서비스, 연관 검색어, 네이버 메이트 추천, AI 브리핑, 네이버 클립, 동영상 묶음 영역을 제외합니다.
- 독립된 일반 결과 카드의 대표 제목을 화면의 위→아래, 같은 높이면 왼쪽→오른쪽 순서로 셉니다. 댓글과 카드 내부의 관련 링크는 별도로 세지 않습니다.
- 다음 통합검색 페이지에 표시된 결과를 이어서 셉니다. 같은 글이 별도 카드로 다시 노출되면 각각 셉니다.
- 요청 범위를 모두 읽지 못하거나 지원하지 않는 화면 구조가 발견되면 순위를 추정하지 않고 오류를 표시합니다.
- 네이버의 공식 순위가 아닌 위 기준에 따른 관측값이며, 시점·지역·접속 환경에 따라 달라집니다.

`창원 파킨슨병`, `창원 진전증`, `창원 배열증`에서 클립·동영상 영역 때문에 발생하던 조회 중단을 수정했습니다. `창원 어지럼증`의 기존 신고는 별도 재검증이 필요합니다. 지원하지 않는 새 검색 화면 구조는 오류로 안내합니다.

## 검증 및 진단

```sh
npm test
npm run probe -- "창원 하지불안증후군" "휴한의원 창원" 20
```

진단 명령은 `debug/`에 화면과 수집 결과를 저장합니다. 이 폴더는 Git에 포함하지 않습니다. 테스트에는 실제 네이버 순위를 고정값으로 가정하지 않는 이름 비교·정렬·제외 영역·다중 블로그 비교 검증이 포함됩니다.

## 파일 구성

| 경로 | 역할 |
|---|---|
| `public/` | 입력 화면과 비교표 |
| `src/server.mjs` | 로컬 웹서버 |
| `src/collector.mjs` | 통합검색 접속과 페이지 이동 |
| `src/extract.mjs` | 제목·블로그명·위치 추출 |
| `src/exclusions.mjs` | 제외 영역 기준 |
| `src/ranking.mjs` | 정렬·정확한 이름 비교·순위 |
| `src/batch.mjs` | 한 키워드에 여러 블로그 비교 |
| `test/` | 자동 검증 |

데이터베이스·회원가입·결제·자동 예약·조회 기록 저장 기능은 없습니다. 자세한 사용법은 [사용안내.md](사용안내.md)를 참고하세요.
